# Management Insights: Supply Chain & Sales Performance

## 📌 Project Overview
This project involved the creation of a high-level executive dashboard to track **Sales, Profit, and Warehouse Efficiency**. By treating the supply chain like a control system, this dashboard identifies "hot spots" where operational costs are high relative to revenue.

## 📈 Executive Summary
* **Total Sales:** $154.57M
* **Total Profit:** $57.79M
* **Average Profit Margin:** 37.39%
* **Operational Efficiency:** Identified specific warehouse codes and cities (e.g., Sydney, Albury) that contribute disproportionately to total revenue.

## 🔍 Dashboard Features
* **Territory Mapping:** Geospatial visualization of sales distribution across various regions.
* **Channel Analysis:** Comparative view of revenue generated via different sales channels (Distribution, Wholesale, etc.).
* **Drill-Down Capabilities:** Users can filter by Year, Quarter, and specific Metrics (Revenue vs. Cost) to perform root-cause analysis on profit dips.

## 🛠 Tech Stack
* **Tool:** Power BI
* **Data Modeling:** DAX (Data Analysis Expressions) for profit margin and growth calculations.
* **Visuals:** Map charts, Treemaps, and Time-series trend lines.
